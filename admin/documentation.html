📚 Documentation DS.BAT

Guide complet d'utilisation du site

📸 Ajouter des photos

  1. Allez dans Administration → Gestion des images
  2. Uploadez vos photos JPG ou PNG
  3. Elles sont automatiquement converties en WebP
  4. Copiez le chemin généré (ex: image/uploads/ma-photo.webp)
  5. Utilisez ce chemin dans vos pages HTML

Exemple :

<img src="image/uploads/ma-photo.webp" alt="Description" loading="lazy">

⚡ Modifier les prix

Tous les prix sont dans le fichier config.js à la racine :

prix: {
    electricite: {
        priseSimple: 83.97,    // ← Modifiez ici
        interrupteur: 89.20     // ← Modifiez ici
    }
}

📞 Changer le téléphone

Dans config.js, modifiez :

entreprise: {
    telephone: "06 29 55 66 27",    // ← Nouveau numéro
    email: "contact@dsbat.fr"        // ← Nouvel email
}

🖼️ Structure des dossiers

├── a-convertir/      ← Déposez vos photos JPG/PNG ici
├── chantier-verriere.jpg
├── qrcode-site.png
└── convert.php       ← Script de conversion
